# 基本設計書 — Explainable Semantic Space Explorer

**プロジェクト名:** Explainable Semantic Space Explorer  
**版:** 1.0  
**作成日:** 2026-05-05

---

## 1. 画面構成

| No. | 画面名 | 説明 |
|-----|--------|------|
| 1 | 検索タブ | クエリ語入力・Top-K 類似語表示・コサイン内訳と Z-score の確認 |
| 2 | 比較タブ | 同一クエリに対する Word2Vec / SBERT の差分比較 |
| 3 | 投影タブ | PCA / UMAP による 2D 埋め込み空間の俯瞰 |
| 4 | クラスタタブ | KMeans クラスタリング結果の色分け散布図表示 |

> 本システムはシングルページアプリケーション (SPA) として実装される。タブ切り替えによって画面遷移なしに全操作を完結する。

---

## 2. 画面設計

### 2.1 検索タブ（Top-K 類似語検索）

**レイアウト**

- ページタイトル: `Explainable Semantic Space Explorer`
- サブタイトル: システムの概要を 1 行で説明

**入力エリア**

- ラベル: "クエリ語を入力"
- コンポーネント: `st.text_input`（プレースホルダー: 例: bank, king, computer）
- Top-K スライダー: `st.slider`（範囲: 5〜30、デフォルト: 10）
- 品詞フィルタ: `st.selectbox`（全品詞 / 名詞 / 動詞 / 形容詞 など）
- ボタン: "検索実行"（`st.button`）

**結果表示エリア**

- 検索実行後に表示（ローディングスピナー付き）
- Word2Vec と SBERT の結果を `st.columns(2)` で並列表示
- 各行の表示項目: 順位・類似語・類似度スコア・内積・ノルム（コサイン内訳）・同品詞内順位
- 距離分布: `st.altair_chart` でヒストグラム表示、全語彙平均・標準偏差・Z-score を `st.metric` で提示

### 2.2 比較タブ（Word2Vec vs SBERT 差分）

**入力エリア**

- ラベル: "比較するクエリ語を入力"
- コンポーネント: `st.text_input`
- Top-K スライダー: `st.slider`

**結果表示エリア**

- 共通語・Word2Vec 固有語・SBERT 固有語の件数を `st.metric` で表示
- 共通語の順位差分・距離差分を `st.dataframe` で表示（差分の大きい順に降順ソート）

### 2.3 投影タブ（2D 空間投影）

**入力エリア**

- クエリ語: `st.text_input`
- 投影手法: `st.selectbox`（PCA / UMAP）
- Top-K: `st.slider`
- seed: `st.number_input`

**結果表示エリア**

- `st.altair_chart` で 2D 散布図を表示
- PCA 選択時: 第 1・第 2 主成分の寄与率を `st.metric` で表示
- クエリ語を強調マーカーで表示

> **既知課題:** クエリ語マーカーの凡例と図上の表示が一致しない不具合が残存している（詳細は `CLAUDE.md` 「既知の課題」を参照）。

### 2.4 クラスタタブ（KMeans クラスタリング）

**入力エリア**

- クエリ語: `st.text_input`
- クラスタ数: `st.slider`（デフォルト: 8）
- seed: `st.number_input`

**結果表示エリア**

- `st.altair_chart` でクラスタ色分け散布図を表示
- クラスタ ID を色・凡例で識別
- 各クラスタの代表語リストを `st.expander` で展開表示

## 3. 入出力定義

### 3.1 入力（クエリ語）

| 項目 | 詳細 |
|------|------|
| フィールド名 | クエリ語 |
| 入力方法 | テキストボックスへの手動入力 |
| データ型 | `str` |
| 必須 / 任意 | 必須 |
| 大文字・小文字 | 小文字に正規化して検索する |
| バリデーション | 空文字・語彙外の語はエラーメッセージを表示して処理を中断する |

**入力例**

```
bank
```

### 3.2 出力（類似語リスト）

出力形式: Streamlit UI のテーブルおよびメトリクス表示

| フィールド名 | 型 | 説明 |
|---|---|---|
| rank | int | 類似度順位（1 始まり） |
| word | str | 類似語 |
| similarity | float | コサイン類似度（-1.0〜1.0） |
| dot_product | float | 内積 a · b |
| norm_a | float | クエリ語のノルム ‖a‖ |
| norm_b | float | 類似語のノルム ‖b‖ |
| pos_tag | str | 品詞ラベル（例: NN, VB, JJ） |
| pos_rank | int | 同品詞内の順位 |
| z_score | float | 全語彙分布における Z-score |

**出力例（UI 表示イメージ）**

```

Word2Vec 結果（Top-5）
1. river    | cos: 0.712 | dot: 14.2 | ‖a‖: 4.47, ‖b‖: 4.46 | NN / 同品詞 1 位
2. shore    | cos: 0.698 | dot: 13.9 | ...
3. creek    | cos: 0.681 | ...
Z-score: 3.21（全語彙平均: 0.12、std: 0.18）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SBERT 結果（Top-5）
1. financial | cos: 0.724 | dot: 18.1 | ...
2. credit    | cos: 0.711 | ...
```

> 同一の "bank" でも、Word2Vec では地理的意味（river, shore）、SBERT では金融的意味（financial, credit）の語が上位に現れる。これが本システムの主要な説明対象である。

## 5. システムアーキテクチャ

### 5.1 層構造と依存方向

本システムは **assets → core → analysis → ui** の 4 層で構成する。依存方向は一方向のみ。逆流禁止。

```
data/ ──► core/ ──► transforms/ ──► ui/app.py
```

| 層 | ディレクトリ | 役割 | 禁止事項 |
|---|---|---|---|
| データ層 | `data/` | 事前生成済みベクトル・語彙・品詞・整合仕様の保持 | 動的生成・編集 |
| ロジック層 | `core/` | 埋め込みロード・距離計算・類似度検索・品詞フィルタ・距離分布解析 | Streamlit import・外部 API 呼び出し |
| 前処理層 | `transforms/` | 次元削減（PCA / UMAP）・クラスタリング（KMeans） | UI への依存 |
| UI 層 | `ui/` | Streamlit による画面構築・操作受付・結果表示 | 分析ロジックの直書き |

### 5.2 主要クラス一覧

**`core/` — コアロジック層**

| クラス | 役割 |
|---|---|
| `EmbeddingLoader` | `data/` 配下のベクトル・語彙・品詞・`manifest.json` を読み込み、整合性を検証する |
| `DistanceMetrics` | コサイン類似度の自前実装を提供する（scipy / sklearn の `cosine_similarity` は使用しない） |
| `SimilarityEngine` | 1 インスタンス = 1 モデル（Word2Vec または SBERT）。Top-K 検索・モデル間比較を担う |
| `POSFilter` | 品詞ラベルに基づくフィルタリング・同品詞内順位・異品詞率の算出を担う |
| `DistanceAnalyzer` | 距離分布統計（平均・標準偏差・Z-score・ヒストグラム生データ）を提供する |

**`transforms/` — 前処理層**

| クラス | 役割 |
|---|---|
| `Projector` | PCA / UMAP による 2D 投影を提供する。seed 固定で再現性を保証する |
| `KMeansClusterer` | L2 正規化後の KMeans によりコサインベースのクラスタリングを行う |

### 5.3 資産ファイル仕様

| ファイル | shape | dtype | 概算容量 |
|---|---|---|---|
| `data/embeddings/static_vectors.npy` | (83823, 300) | float32 | 約 96 MB |
| `data/embeddings/contextual_vectors.npy` | (83823, 384) | float32 | 約 123 MB |
| `data/metadata/vocab.json` | 83823 件 | UTF-8 JSON | 約 1.2 MB |
| `data/metadata/vocab_pos.npy` | (83823,) | 文字列配列 | 約 2.9 MB |
| `data/manifest.json` | — | UTF-8 JSON | 数 KB |

語彙数 N = 83823 で全ファイルが一致していることが整合性検証の前提である。起動時に `manifest.json` との shape / dtype 照合を行い、不整合は `ManifestViolationError` として即座に検出する。
