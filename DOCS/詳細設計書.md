### 2.2 `core/similarity_engine.py`

**役割:** 単一の埋め込み行列に対する Top-K 類似語検索・モデル間比較・距離分布計算。1 インスタンス = 1 モデル（Word2Vec または SBERT）。

**主要メソッド**

| メソッド | シグネチャ | 説明 |
|---------|-----------|------|
| `__init__` | `(vectors: np.ndarray, vocab: Dict[str,int], pos_tags: np.ndarray, metrics: DistanceMetrics) -> None` | 各引数を型検証。`_index_to_word` リストを構築 |
| `search` | `(self, query_word: str, top_k: int = 10, pos_filter: str \| None = None) -> List[SearchResult]` | Top-K 類似語を降順で返す。品詞フィルタは Top-K 抽出後に適用 |
| `compare` | `(self, query_word: str, other: "SimilarityEngine", top_k: int = 10) -> ComparisonResult` | self と other の Top-K を比較し共通語・固有語・差分を返す |
| `get_distance_distribution` | `(self, query_word: str) -> dict` | 全語彙との類似度分布統計（mean / std / top1 / z_score / histogram_data） |
| `word_to_index` | `(self, word: str) -> int` | 語彙外なら `UnknownWordError` |

**データクラス**

`SearchResult`: `word, index, similarity, rank, pos_tag, pos_rank, explanation`  
`ComparisonResult`: `query_word, static_results, contextual_results, common_words, static_only, contextual_only, rank_diff, similarity_diff`

**送出例外:** `UnknownWordError` / `InvalidTopKError` / `TypeError`  
**外部依存:** `numpy`, `DistanceMetrics`

### 2.3 `core/distance_metrics.py`

**役割:** コサイン類似度の完全自前実装。`scipy` / `sklearn.cosine_similarity` 不使用。全メソッドは `staticmethod`。

**主要メソッド**

| メソッド | シグネチャ | 数式 |
|---------|-----------|------|
| `l2_norm` | `(vector: np.ndarray) -> float` | `‖v‖ = √(v · v)` |
| `cosine_similarity` | `(vec_a: np.ndarray, vec_b: np.ndarray) -> float` | `(a · b) / (‖a‖ × ‖b‖)` |
| `cosine_similarity_batch` | `(query: np.ndarray, matrix: np.ndarray) -> np.ndarray` | 全行を一括計算。`_EPSILON = 1e-10` でゼロ除算ガード |
| `explain` | `(vec_a: np.ndarray, vec_b: np.ndarray) -> Dict[str, Any]` | `dot_product / norm_a / norm_b / denominator / similarity / formula` を辞書で返す |

**バッチ計算の実装方針**

```python
dot_products = matrix @ query
row_norms    = sqrt(sum(matrix * matrix, axis=1))   # np.linalg.norm 不使用
denominators = row_norms * query_norm
similarities = dot_products / where(zero_mask, 1.0, denominators)
similarities[zero_mask] = 0.0
```

**送出例外:** `TypeError` / `VectorDimensionError`  
**外部依存:** `numpy` のみ

### 2.4 `core/pos_filter.py`

**役割:** `SearchResult` リストへの品詞フィルタ適用・グループ化・異品詞率算出。全メソッドは `staticmethod`。

**主要メソッド**

| メソッド | シグネチャ | 説明 |
|---------|-----------|------|
| `filter` | `(results: List[SearchResult], pos_tag: str) -> List[SearchResult]` | 指定品詞のみ残す。空文字なら `ValueError`、該当なしなら `UnknownPOSTagError` |
| `group_by_pos` | `(results: List[SearchResult]) -> Dict[str, List[SearchResult]]` | 品詞ごとにグループ化（元順序を保持） |
| `pos_distribution` | `(results: List[SearchResult]) -> Dict[str, int]` | 品詞ごとの件数集計（件数降順） |
| `heterogeneity_rate` | `(results: List[SearchResult], query_pos: str) -> float` | 異品詞率 = クエリ語と異なる品詞の語の割合（範囲: [0.0, 1.0]） |
| `assign_pos_ranks` | `(results: List[SearchResult]) -> List[SearchResult]` | 同品詞内順位を 1 から連番で付与 |
| `top_pos` | `(results: List[SearchResult], n: int = 3) -> List[str]` | 出現件数上位 n 品詞を返す |

**異品詞率の計算式**

```
heterogeneity_rate = |{r ∈ results | r.pos_tag ≠ query_pos}| / |results|
```

`0.0` = 全結果が同品詞（完全に品詞依存）、`1.0` = 全結果が異品詞（品詞非依存）。

**外部依存:** `SearchResult`（`similarity_engine.py` で定義）

### 2.5 `core/analyzer.py`

**役割:** 距離分布の統計拡張・ヒストグラム生成・モデル間分布比較・近傍安定性算出。全メソッドは `staticmethod`。

**主要メソッド**

| メソッド | シグネチャ | 説明 |
|---------|-----------|------|

| `neighborhood_stability` | `(static_results, contextual_results) -> float` | Jaccard 係数 = 両モデル Top-K の共通語割合 |

**データクラス:** `DistributionStats` / `HistogramData` / `DistributionComparison`  
**外部依存:** `numpy`, `SearchResult`, `ComparisonResult`

## 3. データフロー

### 起動・ロードフロー

1. `ui/app.py`: `load_all_engines()` を `@st.cache_resource` でキャッシュ（プロセス内で 1 回のみ実行）
2. `EmbeddingLoader(Path("data")).load_all()`:
   - `manifest.json` を読み込み整合チェック設定を構築
   - `static_vectors.npy` / `contextual_vectors.npy` を `np.load`
   - `vocab.json`（リスト形式）を `Dict[str, int]` に変換
   - `vocab_pos.npy` を読み込み
   - shape / dtype / N 一致を検証（不整合は処理中断・例外送出）
3. `static_engine = SimilarityEngine(loader.static_vectors, loader.vocab, loader.pos, metrics)`
4. `contextual_engine  = SimilarityEngine(loader.contextual_vectors, loader.vocab, loader.pos, metrics)`
5. ロード完了 → Streamlit UI レンダリング開始

### 類似語検索フロー

1. 利用者がクエリ語・Top-K・品詞フィルタを入力しボタンを押す
2. `SimilarityEngine.word_to_index(query_word)` → 語彙外なら E002 エラー表示で中断
3. `DistanceMetrics.cosine_similarity_batch(query_vec, vectors)` → 全 N 件の類似度算出
4. `np.argpartition` で Top-K を抽出（O(N + k log k)）
5. `POSFilter.assign_pos_ranks` で同品詞内順位を付与
6. `DistanceMetrics.explain` で内積・ノルム内訳を `SearchResult.explanation` に格納
7. `Analyzer.attach_z_scores` で全語彙分布に対する Z-score を付与
8. UI: 類似語リスト・コサイン内訳・Z-score を表形式で表示

### 比較フロー（Word2Vec vs SBERT）

1. `static_engine.search(query_word, top_k)` → `static_results`
2. `contextual_engine.search(query_word, top_k)` → `contextual_results`
3. `static_engine.compare(query_word, other=contextual_engine, top_k)`:
   - `set` 演算で `common_words` / `static_only` / `contextual_only` を生成
   - 共通語ごとに `rank_diff` / `similarity_diff` を算出
4. `Analyzer.neighborhood_stability(static_results, contextual_results)` → Jaccard 係数
5. UI: 共通語・固有語件数、差分ランキングテーブルを表示

### 投影・クラスタフロー

1. `static_engine.search(query_word, top_k)` → 近傍語インデックス取得
2. `target_indices = neighbor_indices + [query_idx]`（クエリ自身を必ず含める）
3. `target_vectors = loader.static_vectors[target_indices]`
4. `KMeansClusterer(n_clusters=k, seed=42).fit(target_vectors)`:
   - L2 正規化 → `sklearn.KMeans.fit` → `ClusterResult.labels` を取得
5. `Projector(method=method, seed=42).fit_transform(target_vectors)`:
   - PCA または UMAP で 2D 座標を生成
6. `projector.attach_clusters(projection_result, cluster_labels)` → クラスタ ID 付き結果
7. UI: Altair `mark_point` + `mark_text` で散布図を描画

## 5. アルゴリズム設計

### Top-K 検索（`argpartition` による O(N + k log k)）

```python
all_sims = DistanceMetrics.cosine_similarity_batch(query_vec, vectors)  # O(N·D)
all_sims[query_idx] = -np.inf                                           # 自己除外
effective_k = min(top_k, n_vocab - 1)
top_k_unordered = np.argpartition(all_sims, -effective_k)[-effective_k:]  # O(N)
sorted_order    = np.argsort(all_sims[top_k_unordered])[::-1]             # O(k log k)
top_k_indices   = top_k_unordered[sorted_order]
```

全語彙ソート O(N log N) を回避。`effective_k = min(top_k, N-1)` により `top_k > N-1` でも安全。

### コサイン KMeans（L2 正規化の等価性）

単位ベクトル `â = a/‖a‖`、`b̂ = b/‖b‖` に対して:

```
‖â - b̂‖² = ‖â‖² - 2·â·b̂ + ‖b̂‖² = 2 - 2·cos(a, b)
```

正規化後の空間ではユークリッド距離の最小化がコサイン距離の最小化と等価になるため、`sklearn.KMeans`（ユークリッド前提）でコサイン KMeans が成立する。

### PCA 寄与率

入力行列 `X ∈ R^{N×D}` の共分散行列の固有値 `λ_i` を用いて:

```
Z = X · V^T             （V: 上位 2 主成分を行に持つ行列）
寄与率_i = λ_i / Σ_j λ_j
```

`Projector._fit_pca` は `sklearn.PCA(n_components=2, random_state=seed)` を使用し、`explained_variance_ratio_.tolist()` を `ProjectionResult.explained_variance` に格納する。

### Z-score 計算

```
z = (top1_similarity - mean) / std
```

`std == 0.0` のとき `z_score = 0.0`（ゼロ除算回避）。全 N-1 件（自己除外）の類似度分布に対して算出する。

## 6. 定数・設定値

### 主要定数

| `SUPPORTED_METHODS` | `("pca", "umap")` | `projection.py` | 有効な投影手法名 |
| `DEFAULT_TOP_K` | `10` | `similarity_engine.py` | `search()` のデフォルト Top-K |
| `DEFAULT_N_CLUSTERS` | `8` | `clustering.py` | KMeans のデフォルトクラスタ数 |
| `DEFAULT_SEED` | `42` | `clustering.py`, `projection.py` | 乱数シードのデフォルト値 |
| `DEFAULT_MAX_ITER` | `300` | `clustering.py` | KMeans の最大反復数 |
| `N_HISTOGRAM_BINS` | `50` | `analyzer.py` | ヒストグラムのデフォルトビン数 |

### seed 固定箇所

| 箇所 | seed の渡し方 |
|------|-------------|
| `KMeansClusterer.__init__` | `KMeans(random_state=self._seed)` |
| `Projector.__init__`（PCA） | `PCA(random_state=self._seed)` |
| `Projector.__init__`（UMAP） | `UMAP(random_state=self._seed)` |
| `ui/app.py` Tab 4 | `KMeansClusterer(seed=42)` / `Projector(seed=42)` で直接指定 |

`ClusterResult.seed` / `ProjectionResult.seed` に使用した seed を保存し、結果から再現性を確認できる。

│   ├── NotFittedError            # 未 fit でアクセス

└── ProjectionError
    ├── NotFittedError            # 未 fit でアクセス（clustering.py とは別クラス）
