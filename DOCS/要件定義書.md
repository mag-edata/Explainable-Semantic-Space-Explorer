# 要件定義書 — Explainable Semantic Space Explorer

**プロジェクト名:** Explainable Semantic Space Explorer  
**版:** 1.0  
**作成日:** 2026-05-05

---

## 1. 目的と背景

- NLP の実務では単語埋め込みが広く使われているが、「なぜその単語が近いのか」を数値で説明する手段がなく、ブラックボックスになりがちである。
- 本システムは静的埋め込み（Word2Vec）と文脈埋め込み（SBERT）を並列比較し、類似度の算出過程を内積・ノルムの形式で分解して提示することで、埋め込み空間の挙動を説明可能にする。
- 目的は NLP の精度最大化ではなく、**「説明可能な NLP 設計」の意思決定能力を示すこと**にある。

---

## 2. 課題定義

- **現状:** 実務者は埋め込みモデルが出力した類似度スコアを見て判断するが、その根拠を数値で説明できない。

- **課題 1（説明可能性の欠如）:** 「"king" の近傍に "queen" が出る」は知っていても、なぜ近いのかを内積・ノルムの水準で説明できない。

- **課題 2（モデル間比較の困難）:** Word2Vec（静的）と SBERT（文脈）は同一単語を異なる意味空間位置に配置するが、この差を定量的に比較する手段が乏しい。

- **課題 3（スコアの相対評価困難）:** 類似度スコア 0.82 が「高い」のか「普通」なのか、語彙全体の分布を参照しなければ判断できない。

本システムは、課題 1 をコサイン類似度の分解表示と Z-score により、課題 2 を静的・文脈埋め込みの並列比較により、課題 3 を距離分布統計（ヒストグラム・平均・標準偏差）により解決する。

---

## 3. システム概要

- 入力: クエリ語（任意の英単語）
- 出力: Word2Vec / SBERT それぞれにおける Top-K 類似語、モデル間差分比較、コサイン類似度の内訳、距離分布統計、2D 投影・クラスタ散布図
- バックエンド: `core/`（類似度ロジック）・`transforms/`（PCA / UMAP / KMeans）
- フロントエンド: Streamlit（4 タブ構成）
- データ: 事前生成済みローカル `.npy` ファイル（語彙数 83,823）

| ファイル | shape | dtype | 説明 |
|---|---|---|---|
| `static_vectors.npy` | (83823, 300) | float32 | Word2Vec 静的埋め込み |
| `contextual_vectors.npy` | (83823, 384) | float32 | SBERT 文脈埋め込み |
| `vocab.json` | 83823 件 | — | 語彙リスト |
| `vocab_pos.npy` | (83823,) | — | 品詞ラベル配列 |
| `manifest.json` | — | — | shape / dtype 期待値 |

外部 API 不使用。ローカル CPU 環境のみで完全動作する。

---

## 4. 機能要件

### 4.1 類似語検索

- 利用者が入力した単語に対して、Word2Vec 埋め込みにおける Top-K 類似語を出力できること（FR-01）
- 同一の入力語に対して、SBERT 埋め込みにおける Top-K 類似語を出力できること（FR-02）
- 各類似語について、類似度スコア・順位・同品詞内順位・異品詞率を併せて提示できること（FR-03）

### 4.2 静的 vs 文脈 差分比較

- 同一クエリ語の Word2Vec / SBERT それぞれの Top-K 類似語に対し、共通語数・固有語数を提示できること（FR-04）
- 共通語について、モデル間の順位差分・距離差分を提示できること（FR-05）
- 差分の大きさで並び替えた差分ランキングを出力できること（FR-06）

### 4.3 距離分布分析

- クエリ語と全語彙とのコサイン類似度の分布をヒストグラム形式で可視化できること（FR-07）
- 全語彙平均・標準偏差・Top-1 類似度を数値として出力できること（FR-08）
- Top-1 類似度の異常度を Z-score として算出できること（FR-09）

### 4.4 2次元投影

- 埋め込みベクトルを 2 次元へ投影できること（手法: PCA / UMAP の選択可能）（FR-10）
- PCA を用いた場合、主成分の寄与率を併せて表示できること（FR-11）
- 投影結果上に各点のクラスタ ID を付与して表示できること（FR-12）

### 4.5 クラスタリング

- 埋め込みベクトルをクラスタリング（KMeans）し、各語にクラスタ ID を付与できること（FR-13）
- クラスタ数および乱数 seed を利用者が指定でき、同一指定では同一結果が得られること（FR-14）

### 4.6 品詞フィルタ

- 類似語検索結果を品詞単位で絞り込めること（FR-15）
- 検索結果の異品詞率（クエリ語と異なる品詞の語が含まれる割合）を算出できること（FR-16）

### 4.7 説明情報の付与

- 各出力に対し、距離計算式・全語彙平均との差・品詞影響の有無・クラスタ所属・コーパス頻度のうち該当する項目を併記し、「なぜ近いのか」に数値で答えられること（FR-17）

## 5. 非機能要件

### パフォーマンス

| 処理 | 目標 |
|---|---|
| Top-K 類似語検索 + 距離分布算出 | 5 秒以内（語彙数 10 万語以下を想定） |
| PCA 2D 投影 | 10 秒以内 |
| KMeans クラスタリング（k=8、語彙全体） | 30 秒以内 |

### 再現性

- 乱数を用いる処理（クラスタリング・UMAP 等）はすべて seed を固定し、同一入力に対し 100% 再現性を持つこと（NFR-01）
- `manifest.json` による shape / dtype の整合チェックを起動時に必ず実施し、不整合は明示的に検出すること（NFR-02）

### 動作環境

- ローカル CPU 環境でのみ動作保証し、GPU を必須としないこと（NFR-05）
- 動作言語・ランタイムは Python 3.12 とすること（NFR-06）
- 推論時にネットワーク接続を必要としないこと（NFR-07）

### 説明可能性

- すべての主要出力に対して、距離計算の数式・関連する統計量（全語彙平均との差、Z-score）・品詞影響の有無を併記し、ブラックボックス化しないこと（NFR-08）

### 保守性

- コアロジックはクラス設計を優先し、関数型より構造化された実装とすること（NFR-09）
- 全引数・戻り値に型ヒントを付与し、全クラス・全メソッドに Docstring を記述すること（NFR-10）
- 例外は用途別のカスタム例外クラスを定義し、汎用例外への一括 raise を行わないこと（NFR-11）

## 6. 制約条件

| 項目 | 内容 |
|---|---|
| 言語 | Python 3.12 |
| 静的埋め込み | Word2Vec（学習済みモデル、ローカル配置） |
| 文脈埋め込み | SBERT（all-MiniLM-L6-v2、ローカル配置） |
| 外部 API | 使用禁止（CONST-01） |
| HuggingFace ダウンロード | セットアップ時の資産生成スクリプト実行時のみ許可（CONST-02） |
| コサイン類似度 | 自前実装必須。scipy / sklearn の cosine_similarity 使用禁止（CONST-04） |
| 推論時ベクトル | 事前保存済みのものに限る（CONST-03） |
| 学習処理 | 推論時は禁止（CONST-05） |
| 乱数 | 使用時は必ず seed 固定（CONST-06） |
| データ整合 | manifest.json による shape / dtype チェック必須（CONST-07） |

## 7. 用語定義

| 用語 | 定義 |
|---|---|
| 単語埋め込み（Embedding） | 単語を実数値ベクトルに変換した表現。意味的に近い単語ほどベクトル空間上で近い位置にあるよう学習される |
| 静的埋め込み（Word2Vec） | 文脈に依存せず、語ごとに 1 つの固定ベクトルを割り当てる埋め込み手法 |
| 文脈埋め込み（SBERT） | Sentence-BERT。Transformer ベースのモデルにより文脈を加味した埋め込みを生成する手法 |
| コサイン類似度 | 2 ベクトルのなす角の余弦。値域は -1〜1、ベクトル方向の近さを表す。`cos(a,b) = (a · b) / (‖a‖ · ‖b‖)` |
| Z-score | 値が分布平均からどれだけ標準偏差単位で離れているかを表す指標。`z = (x - mean) / std` |
| Top-K 類似語 | クエリ語に対して類似度の高い順に上位 K 件を抽出した語の集合 |
| 品詞（POS） | 名詞・動詞・形容詞などの語の文法的分類 |
| PCA | 主成分分析（Principal Component Analysis）。分散最大方向を新しい軸に取る線形次元削減手法 |
| UMAP | Uniform Manifold Approximation and Projection。多様体構造を保ちつつ次元削減する非線形手法 |
| KMeans | データを K 個のクラスタへ分割するクラスタリング手法。本システムでは L2 正規化により実質的にコサイン距離での分割を行う |
| manifest.json | 資産ファイルの shape / dtype の期待値を記述した整合チェック用ファイル |
